# Kemo - Kubernetes Demo Runner

## Commands
- `just health-check` - Validate environment (check dependencies + cluster)
- `just validate-demos` - Lint and validate all demo YAML manifests
- `just run-demo <demo> <variant>` - Run a specific demo (e.g., `just run-demo hello-world good`)
- `just kubernetes-setup` - Setup K8s cluster (OrbStack or Minikube)
- `just kubernetes-cleanup` - Clean up K8s environment
- `yamllint -c .yamllint demos/` - Lint YAML files

## Architecture
- **Shell-based**: All scripts are Bash; uses `just` as the command runner
- **demos/**: Demo scenarios with `good/` (working) and `bad/` (broken) variants
- **scripts/**: Core functionality (demo-stepper.sh, run-demo.sh, select-demo.sh, validate-demos.sh)
- **manifests/**: Shared Kubernetes manifests (ingress, dashboard configs)
- **certs/**: TLS certificates generated by mkcert

## Code Style
- Shell scripts use `#!/usr/bin/env bash` with `set -euo pipefail`
- YAML follows `.yamllint` rules (indentation enabled, line-length disabled)
- Demo metadata in `metadata.yaml` with: name, description, tags, objectives, observations
- Use `gum` for styled CLI output (spinners, prompts, confirmations)
- Hostnames follow `<demo>-<variant>.k8s.orb.local` (OrbStack) or `<demo>-<variant>.k8s.mk.local` (Minikube)
